## Screen Design Evolution

The system design was developed through an iterative versioning process, starting from early concept diagrams and gradually refining toward a consolidated final version.

Instead of a single linear design path, the work was structured into explicit versions:

- initial exploration of screen structures (`first_version.pdf`)
- iterative refinement of interaction flows (`iterations/`)
- consolidated and finalized system design (`final_version.pdf`)

The iteration process focused on:

- usability-driven refinements
- clarification of navigation and system behavior
- progressive detailing of interaction states
- alignment with findings from usability testing

---

## Iteration Structure

### 1. First Version (Conceptual Phase)

- Initial system layout and screen structure
- Early definition of main user flows
- Exploration of calendar, input, and overview concepts

📄 `first_version.pdf`

---

### 2. Iterative Development Phase

The design was refined through multiple iterations based on usability considerations and internal reviews.

Key changes included:

- improved navigation clarity
- refinement of interaction flows
- addition of system feedback states
- clarification of modal and popup behavior

📁 `iterations/`

---

### 3. Final Version

- Consolidated and cleaned-up design system
- Improved consistency across screens
- Reduced ambiguity in interaction logic
- More structured UI hierarchy

📄 `final_version.pdf`

---

The evolution from the first to the final version reflects how usability findings influenced navigation structures, interaction flows, and system feedback mechanisms.

## Outcome

This iterative process resulted in a more coherent and user-centered interface design.

Key improvements included:

- clearer navigation and information hierarchy
- more consistent interaction patterns
- better handling of edge cases (errors, confirmations, empty states)
- improved alignment between design and usability findings
