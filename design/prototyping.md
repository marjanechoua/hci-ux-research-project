## Paper Prototype Overview

This section presents the paper prototypes developed to support and validate the core interaction flows of the application during the design phase.

The prototypes were created as part of an iterative team process to explore and communicate early design decisions before implementation and evaluation.

They focus on the following key interaction areas:

- financial overview and dashboard
- expense input flow
- calendar interaction system
- analytics & forecasting
- system feedback, validation & error handling

---

## 1. Overview & Account Dashboard

### Purpose

Provide users with a clear financial overview and a central entry point into the system.

### Screens
